# Figma Design Library

Central repository for design-system resources, reusable templates, mockups, assets, references, and project documentation.

## Getting started

1. Start with [foundations](design-systems/foundations/README.md) when creating a Figma library or product UI.
2. Use the component specifications in `design-systems/components` to build reusable variants.
3. Compose screens from the documented patterns and templates.
4. Add project-specific visual resources through the asset manifest.

## Structure

- `design-systems/` — foundations, components, and reusable UI patterns.
- `templates/` — page and application templates by use case.
- `mockups/` — device, browser, and presentation mockups.
- `assets/` — shared icons, illustrations, logos, backgrounds, and gradients.
- `references/` — curated UI inspiration, typography, and layout references.
- `docs/` — contribution, naming, and usage guidance.
- `figma/` — Figma REST API source configuration and local sync guidance.
