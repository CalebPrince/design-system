# Components

Each component should expose documented variants, sizes, states, accessibility behavior, and usage guidance. Create components with Auto Layout and properties; publish only stable variants to the shared Figma library.

| Component | Starter contract |
| --- | --- |
| Buttons | intent, size, icon position, loading, disabled |
| Inputs | label, value, helper/error text, required, disabled |
| Cards | padding, surface, media, actions |
| Navigation | active item, collapsed state, responsive behavior |
| Modals | size, title, body, actions, dismiss behavior |
| Tables | density, sort, selection, empty and loading states |
| Forms | field grouping, validation, submission feedback |
| Indicators | state, size, label |
| Ecommerce | quantity, pricing, discount state |
| Marketing | alignment, size, color-on-background |
