# Card

Use cards to group related content and actions. Offer `default`, `outlined`, and `interactive` variants. Keep padding at 16px or 24px; interactive cards need hover, focus, and pressed feedback.

## Content-card variants (source: TailGrids, see `docs/figma-source.md`)

- **Pricing** — `default`/`active` (highlighted plan) states.
- **Product** — `default`/`hover` states; optional discount badge and `big`/`small` featured size.
- **Blog / Team / Portfolio / Service / Product category** — media + heading + supporting text grid cards; portfolio adds a `hover` reveal state.
- **Comment reply** — nested reply card under a parent comment.
- **Chat list item / User list item** — avatar, name, and status row; `default`/`hover` states, optional online indicator or notification badge.
