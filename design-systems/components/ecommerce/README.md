# Ecommerce

Cart and checkout line items. Always show quantity, unit price, and line total; discounted items must show the original price struck through alongside the discounted price.

Variants (source: TailGrids, see `docs/figma-source.md`):

- **Shopping cart item** — compact row, detailed row, and table-row layouts; `discount on`/`off` for the table-row layout.
- **Item badge** — see [Indicators](../indicators/README.md); use on cart/product thumbnails for `new`/`hot` tagging.
