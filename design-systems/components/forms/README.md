# Forms

Group related fields with a meaningful heading. Validate on an appropriate interaction boundary, preserve entered values after errors, and place the primary submit action at the end of the flow.

## Selection controls (source: TailGrids, see `docs/figma-source.md`)

- **Box select** — card-style choice control (e.g. plan/option picker); `default`/`hover` states.
- **List select item** — single-line choice row; `default`/`selected` states.
