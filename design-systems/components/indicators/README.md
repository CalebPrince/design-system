# Indicators

Status, progress, and rating elements. Convey state with shape and label, not color alone; keep labels legible at small sizes.

Variants (source: TailGrids, see `docs/figma-source.md`):

- **Steps** — `completed`/`in-progress`/`pending`; horizontal, vertical, and compact presets.
- **Rating star** — `sm`/`md`/`lg`, 1–5 star fill.
- **Rating/review grid** — rating stars combined with reviewer name and comment.
- **Item badge** — `new`/`hot` corner tags for product or content cards.
- **Avatar with text** — avatar + label, optional leading arrow and trailing count badge.
