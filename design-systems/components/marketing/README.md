# Marketing

Brand and section-heading elements used across landing and marketing pages.

Variants (source: TailGrids, see `docs/figma-source.md`):

- **Logo** — `sm`/`lg` sizes, `white`/`dark` color for use on light or dark backgrounds.
- **Logomark** — icon-only mark, `sm`/`lg` sizes, `primary`/`white` color.
- **Section title** — `left`/`center`/`right` alignment, optional supporting description.
- **Page title** — 5 layout styles for page/hero headers.
