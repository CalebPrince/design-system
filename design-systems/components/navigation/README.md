# Navigation

Document top navigation, sidebar, tabs, breadcrumbs, and pagination separately as they mature. Active location must be clear and keyboard focus must remain visible.

## Tab and sidebar variants (source: TailGrids, see `docs/figma-source.md`)

- **Tab menu** — 8 visual styles (underline, pill, boxed, icon-led); each defines `default`/`active`/`hover` states.
- **Sidebar menu item** — `default`/`active` states, each with or without a trailing expand arrow.
- **Drawer item** — single-row item for slide-out/mobile navigation.
- **More options menu** — two compact styles for overflow/kebab actions.
