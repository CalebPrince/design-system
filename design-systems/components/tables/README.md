# Data Table

Include loading, empty, error, selected, and overflow states. Define column alignment, sorting, filtering, pagination, and responsive behavior before publishing the component.

## Grid and stacked-row variants (source: TailGrids, see `docs/figma-source.md`)

- **Table grid** — compact card-grid framing for tabular summary data, two width presets.
- **Table stack list** — row-based alternative to a table for narrow/responsive layouts; `default`/`hover` states, three width presets.
