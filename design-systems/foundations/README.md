# Foundations

Foundations are the shared decisions behind every interface. Start with these token values, then create matching Figma variables, color styles, text styles, effects, and layout grids.

| Area | Starter file | Figma artifact |
| --- | --- | --- |
| Colors | `colors/tokens.json` | Color variables/styles |
| Typography | `typography/tokens.json` | Text styles |
| Spacing | `spacing/tokens.json` | Number variables |
| Grids | `grids/README.md` | Layout grids |
| Elevation | `elevation/tokens.json` | Effect styles |
