# Naming Conventions

Use clear, lowercase, hyphen-separated names for files and folders unless a required product or brand name uses another form.

- Use singular component names: `button`, `modal`, `data-table`.
- Name variant documents with the base name first: `button-primary.md`.
- Use ISO dates in research and inspiration notes: `2026-08-18-dashboard-review.md`.
- Use descriptive asset names: `illustration-empty-state.svg`, not `image-01.svg`.
