# Browser Mockups

Use browser frames for web-product screenshots. Record the viewport width and browser-frame source alongside each export.

## Available browser frames (source: BRIX Browser Mockups kit, see `docs/figma-source.md`)

- **Chrome, Edge, Firefox, Arc, Opera** — macOS and Windows desktop (`light`/`dark` theme) plus Android and iOS mobile. Files: `brix-<browser>-<macos|windows>-<dark|light>.png`, `brix-<browser>-<android|ios>.png`.
- **Safari** — macOS desktop only (`light`/`dark`; no Windows build exists) plus Android and iOS mobile.
- 34 exported PNGs total, pulled live from the kit via the Figma MCP server on 2026-08-18. Drop the target screenshot into the frame's content area; do not alter the chrome (address bar, traffic lights, tab strip).
