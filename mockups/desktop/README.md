# Desktop Mockups

Use desktop device frames for application or website presentations. Keep screen proportions and shadows consistent within a presentation.

## App-window frames (source: BRIX Browser Mockups kit, see `docs/figma-source.md`)

- **Figma, Framer** — macOS and Windows, `light`/`dark` theme. Files: `brix-<figma|framer>-<macos|windows>-<dark|light>.png`.
- **Webflow** — macOS only, single theme. File: `brix-webflow-macos.png`.
- 9 exported PNGs total, pulled live from the kit via the Figma MCP server on 2026-08-18.
