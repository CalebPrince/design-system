# Templates

Templates are starting points for common screen types. Duplicate a template into a product file and replace its content; do not edit the original to support one-off needs.

| Template | Intended use |
| --- | --- |
| `landing-pages` | Product or campaign marketing pages |
| `SaaS` | Authenticated SaaS product shells |
| `dashboards` | Analytics and operational views |
| `portfolios` | Case-study and personal-work showcases |
| `ecommerce` | Shopping and checkout surfaces |
| `agency` | Service and studio sites |
| `mobile-app` | Mobile product flows |
| `admin-panels` | Internal management tools |
